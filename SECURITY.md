## Reporting a Vulnerability

We take the security of this project seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. 

Instead, please report vulnerabilities by choosing one of the following methods:
* **Private Vulnerability Reporting:** Go to the **Security** tab of this repository, click **Vulnerability reporting**, and select **Report a vulnerability**.
* **Email:** Send a detailed report directly to **your-email@example.com** (replace this with your actual email).

### What to Include in a Report
To help us patch the issue quickly, please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions (or a proof-of-concept script) to reproduce the behavior.
3. The specific version(s) of the project affected.

### Response Timeline
* **Acknowledgement:** You will receive a response acknowledging your report within 48 hours.
* **Updates:** We will keep you updated on our progress as we work to validate and fix the issue.
